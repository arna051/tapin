# Security policy

Do not report vulnerabilities in public issues. Contact the repository owner privately. Never include Tapin tokens, authorization headers, addresses, phone numbers, national IDs, financial payloads, or production responses in reports or fixtures.

Tokens belong only on trusted servers. Pin access to the intended server IP when appropriate. Account verification must use a read-only endpoint and must never register a parcel, assign a barcode, deduct wallet credit, or create a payment.
